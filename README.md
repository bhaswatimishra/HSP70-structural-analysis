# HSP70: Computational Exploration of Structure, Sequence and Chaperone Function

## Overview
This project explores selected sequence and structural characteristics
of human HSPA1A (HSP70) using publicly available biological databases
and Python-based analysis.

## Data Sources
- UniProt: HSPA1A (P0DMV8)
- RCSB PDB: 4PO2

## Analysis
- Protein length and molecular weight
- Amino acid composition
- Aromaticity
- GRAVY score
- Instability index
- Sequence-derived secondary structure fractions
- Kyte-Doolittle hydropathy profile
- Sequence-derived flexibility profile
- Correlation between local hydropathy and flexibility
- Functional-region annotations from UniProt

## Tools
- Python
- Biopython
- NumPy
- Pandas
- Matplotlib
- UniProt
- RCSB PDB

## Note
The computational results are sequence-derived predictions/observations
and should not be interpreted as experimental measurements.
